MOUR SMS OTP consent evidence

Brand: Mour App LLC · Site: mourapp.com · App: com.mour.app

Public evidence for Twilio A2P / 10DLC OTP (2FA) campaign. Opt-in occurs only inside the MOUR mobile app. There is no website form opt-in and no keyword text-in opt-in for this campaign.

1. How users opt in

  1. User opens MOUR and chooses phone verification during login/signup.
  2. User enters their own mobile number on the in-app phone screen.
  3. Before tapping SEND SMS CODE, the app shows consent disclosures (rates, HELP, STOP, transactional OTP only, consent not a condition of purchase).
  4. User taps SEND SMS CODE to request a one-time authentication SMS.

2. On-screen consent (byte-aligned)

By requesting a code you agree to receive a one-time MOUR authentication SMS. Messages are transactional OTPs sent only when you request them (on-demand / as needed; not recurring marketing). Message and data rates may apply. Reply HELP for help. Reply STOP to opt out. Consent is not a condition of purchase.

5. Filed message flow (reference)

End users opt in to receive MOUR one-time passcode (OTP) SMS messages only inside the MOUR mobile app (com.mour.app) during login or signup. The user voluntarily enters their own mobile phone number on the in-app phone verification screen and taps a control such as "Send code" or "Continue" to request a verification text. At that step the app shows consent disclosures stating that by requesting a code the user agrees to receive a one-time MOUR authentication SMS; messages are transactional OTPs sent only when the user requests them (message frequency: on-demand / as needed; not recurring marketing); message and data rates may apply; reply HELP for help; reply STOP to opt out. Consent is collected specifically for this OTP campaign and is not obtained from purchased or shared lead lists; consent is not a condition of purchase. There is no website form opt-in and no keyword text-in opt-in for this campaign. Mobile phone numbers and messaging consent are not shared, sold, or provided to third parties or affiliates for marketing or promotional purposes.
